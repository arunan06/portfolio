# 🚀 Arunan | Portfolio Website

A modern, premium portfolio website built with **vanilla HTML, CSS & JavaScript** — featuring particle animations, a magnetic cursor, glassmorphism cards, and a bento-grid layout.

🔗 **Live Website →** [https://arunan06.github.io/portfolio/](https://arunan06.github.io/portfolio/)

---

## ✨ Features

- 🎨 **Dark-mode design** with Electric Blue accent palette
- 🌀 **Particle canvas animation** in the background
- 🖱️ **Custom magnetic cursor** (desktop)
- 🃏 **Glassmorphism cards** with hover glow effects
- 📜 **Scroll-reveal animations** powered by Intersection Observer
- 📱 **Fully responsive** — works on mobile, tablet & desktop
- ⚡ **Zero dependencies** — no frameworks, no build step

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure & semantic markup |
| CSS3 | Styling, animations, glassmorphism |

## 🚀 Getting Started

### Prerequisites

- [Git](https://git-scm.com/downloads) installed on your machine
- A web browser (Chrome, Firefox, Edge, etc.)
- *(Optional)* [VS Code](https://code.visualstudio.com/) or any code editor

### Clone the Repository

```bash
git clone https://github.com/arunan06/portfolio.git
```

### Navigate into the Project

```bash
cd portfolio
```

### Open in Browser

Simply open **`index.html`** in your browser:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

Or use the **Live Server** extension in VS Code for auto-reload during development.

---

## 🌐 Deploy Your Own Version

1. **Fork** this repository on GitHub.
2. Go to your fork's **Settings → Pages**.
3. Under **Source**, select the branch `main` and folder `/ (root)`.
4. Click **Save** — your site will be live at:
   ```
   https://<your-username>.github.io/portfolio/
   ```
